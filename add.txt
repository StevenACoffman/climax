Add (climax add) will create a new command, with
the appropriate structure for a Climax-based CLI application,
and register it to its parent command list.

If you want your command to be public, pass in the command name
with an initial uppercase letter.

Example: climax add server -> resulting in a new cmd/server.go

Usage:
  climax-cli add [command name] [flags]

Aliases:
  add, command

Flags:
  -h, --help            help for add
  -p, --parent string   variable name of parent command for this command (default "rootCmd")
